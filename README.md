## 🚀 Featured Projects

### 🎙️ [1092 Assist — Empathetic AI for Citizen Services](https://github.com/Ravindranbit/ai-call-agent)
Production-grade multilingual AI voice agent built for the **Karnataka Government's 1092 Helpline**, replacing static IVRs with a conversational system that understands citizen distress across English, Hindi, Tamil, and Kannada.
- "Verify Before Action" confirmation loop to prevent AI hallucinations in a high-stakes public service context
- Real-time emotion & urgency detection with automatic human-agent escalation
- Live operations dashboard for transcript review and model feedback
- **Stack:** Node.js, Express, Twilio, Groq (Llama-3), NVIDIA Sarvam-M, Redis, PostgreSQL, Cloudflare Tunnels

### 🏭 [Industrial Knowledge Intelligence](https://github.com/Ravindranbit/industrial-knowledge-intelligence)
An AI knowledge-management platform for **data center cooling operations**, combining a knowledge graph, vector search, and Claude to help technicians diagnose failures and capture institutional expertise before it's lost.
- RAG-powered copilot with cited, confidence-rated answers
- Automated compliance engine checking equipment state against ASHRAE/Tier standards with full reasoning traces
- Structured "tacit knowledge capture" interviews to digitize senior engineers' expertise
- **Stack:** FastAPI, Neo4j AuraDB, PostgreSQL + pgvector, Claude API, Next.js, SQLAlchemy

### 🔎 [NYX — Lost & Found System](https://github.com/Ravindranbit/nyx-app)
A full-stack, cross-platform (Android/iOS/Web/Desktop) lost & found platform built for college campuses, from OTP auth to real-time item matching.
- Secure PASETO-based authentication and OTP verification flow
- Cross-platform Flutter frontend with a Go + Gin REST backend
- **Stack:** Flutter, Go, Gin, PostgreSQL + pgvector, Docker, SQLC

### 📄 [Rezumy — AI Resume Builder](https://github.com/Ravindranbit/Rezumy)
A high-fidelity AI-powered resume builder and portfolio editorial system.
- GitHub OAuth integration with encrypted token storage (AES-128)
- LLM-powered resume parsing and job recommendations
- **Stack:** Next.js (App Router), Prisma, PostgreSQL, TailwindCSS, Groq API, Serper API
